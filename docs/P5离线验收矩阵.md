# P5 离线验收矩阵

更新时间：2026-09-02。验收使用 NDirty 项目内置权重；测试期间不调用联网功能。

| 场景 | 方法 | 结果 |
|---|---|---|
| 启动与诊断 | 离屏启动 Qt 主窗口，打开“本地诊断” | 通过：显示版本、Python、ONNX provider、模型状态与哈希、目录大小和磁盘空间 |
| 模型缺失 | 指向不存在的 LaMa 权重执行推理 | 通过：显示中文可读错误，不尝试下载 |
| 损坏/不支持图像 | 调用图像加载校验 | 通过：显示中文可读错误 |
| 超大图 | 超过 100,000,000 像素的尺寸校验 | 通过：拒绝加载，原文件不变 |
| 中文和含空格路径 | 项目保存/恢复采用 `Path` 与 UTF-8 元数据 | 已有单元回归通过；P6 在干净 Windows 环境做人工复测 |
| 补全质量不变式 | LaMa 合成测试 | 通过：非蒙版像素逐像素保持不变 |
| 取消推理 | `requestInterruption()` 阻止完成信号应用结果 | 已实现；ONNX 当前执行步不可硬中断 |
| 项目保存与导出 | 原子临时文件后替换目标，不允许覆盖输入原图 | 通过单元测试 |
| 离线 OCR/智能选区 | 项目内本地模型、GrabCut 运行 | 通过；不发送图像数据 |
| 依赖完整性 | `python -m pip check` | 通过 |
| 回归 | `python -m pytest -q` | 17 passed |

已知限制：OCR 与 GrabCut 当前在 UI 线程运行，超大图片上可能短暂阻塞；P6/P5.1 应移入工作线程。发行目录尚未构建，因此“发行目录精确大小”留待 P6 的 PyInstaller 产物审计；当前完整开发目录约 921,385,152 字节（0.858 GiB）。
