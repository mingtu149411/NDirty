# NDirty 用户指南（P4）

项目创建者：**南京大学智能化软件专业241880428沈逸文**

NDirty 当前支持本地单张图像预览。可通过工具栏“打开图像”、`Ctrl+O` 或将单张图片拖入窗口导入 PNG、JPG/JPEG、WEBP、BMP。

## 最快使用流程

软件左侧始终显示当前步骤，无需先保存项目或导入蒙版：

1. 点击“导入图片”。
2. 用顶部的“画笔”在遮挡物上涂出红色区域；也可使用矩形、套索或菜单中的文字检测/智能框选。
3. 左侧“补全图像”按钮在蒙版有效后自动可用；点击它直接生成本地补全结果。
4. 检查结果后点击左侧“导出结果”。

“保存项目”和“导入/导出蒙版”位于“项目与辅助工具”菜单，仅用于中断后继续编辑、复用既有蒙版或专业工作流，不是完成一次补全所必需的步骤。修改蒙版后，旧结果会自动失效，避免误导出过期结果。

- 滚轮缩放；工具栏可适配窗口、恢复 100%、放大或缩小。
- 按住空格拖动可平移画布。
- 状态栏显示文件名、原始像素尺寸和缩放比例。
- 软件不会自动缩小、修改或覆盖原图；当前仅在内存中读取并显示图像。
- 为防止内存耗尽，单张图像上限为 100,000,000 像素。超过上限时请先自行制作较小副本。

## 蒙版编辑

- 红色半透明区域是“需要补全”的区域；透明区域是保留区域。
- 使用画笔、橡皮、矩形或套索建立蒙版。笔刷以原图像素为单位，缩放画布不会改变实际笔刷尺寸。
- 可用撤销/重做恢复编辑；历史记录只保存被修改的区域，避免重复复制整幅大图。
- 可导入或导出与原图尺寸一致的 PNG 蒙版。导入时，亮度 ≥128 的像素会转为白色补全区域，其余转为黑色保留区域。
- “清空蒙版”会要求确认，且仍可以使用撤销恢复。

## 项目保存

保存为 `.ndirty` 时，项目文件只保存蒙版、原图路径和原图 SHA-256，不复制原图。重新打开项目时，如原图被移动，软件会要求重新定位原图。

蒙版修改后直接关闭软件时，NDirty 会提示尚未保存。选择“保存项目”可将蒙版存入 `.ndirty` 文件；程序不会覆盖原图。

## 本地诊断与日志

- 工具栏“本地诊断”会显示应用版本、Python、ONNX provider、LaMa 模型存在状态和 SHA-256、应用目录大小及磁盘可用空间。该功能不读取、复制或发送图片内容。
- 遇到技术异常时，界面只显示可读说明；技术日志写入应用目录下的 `logs/ndirty.log`，不记录图像像素或图像副本。

## 辅助选区（P4）

- “检测文字”使用随软件提供的本地 RapidOCR 模型识别文字候选框。点击一个或多个黄色框选中它们，再点击“应用候选”才会加入蒙版；可用“反选候选”批量切换选择，或用“清除文字候选”放弃全部候选；未选中的候选不会改变图像。
- “智能框选”适合边界较清晰的遮挡物：先选择此工具，再用鼠标框住目标。软件在本机以 GrabCut 生成青色候选覆盖层；检查边缘后点击“应用智能选区”才会合并到蒙版。“清除智能选区”只移除预览。
- OCR 和智能框选都是辅助工具，可能漏选或过选。请用画笔、橡皮、矩形或套索修正红色蒙版后再补全。所有处理均在本地离线进行。

## 本地补全与导出

- 选定蒙版后，点击“补全图像”。NDirty 使用随软件提供的 LaMa ONNX 模型在本机 CPU 执行推理；不会上传图片或访问网络。
- 补全是根据周边内容生成的合理图像，不代表恢复了被遮挡区域的真实原始像素。
- 为优先保留细节，软件以蒙版为中心提取保持比例的上下文区域后再推理，而不会把整张横图或竖图强行拉伸为正方形。最终只会替换蒙版内的像素。
- 推理期间界面保持可响应。点击“取消补全”会阻止当前任务完成后应用结果；正在执行的 ONNX 计算会在当前步骤结束后退出。
- 完成后可切换“原图”/“结果”，或拖动结果透明度滑杆叠加比对。结果和叠加模式会自动隐藏红色编辑蒙版，避免遮挡质量判断；可对当前蒙版再次补全。
- 点击“导出结果”保存为 PNG 或 JPEG。默认文件名追加 `_ndirty`，并且程序禁止覆盖输入原图；写入先完成至同目录临时文件，再安全替换目标文件。
