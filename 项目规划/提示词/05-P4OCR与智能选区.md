# Codex 提示词：P4 智能候选区

在 NDirty P3 MVP 上加入辅助检测，但它们只能生成候选，绝不能自动提交蒙版或自动修补。

效果优先约束：候选框/候选掩码必须映射到原图坐标，不能经预览缩放后产生偏移；用户确认前须可精细调整边缘，避免漏选导致残留或过选损伤细节。

按以下顺序实施并在每项后测试：
1. OCR：选择可离线分发、明确许可、体积可控的方案；在 `models/ocr/` 维护权重和哈希。识别中文/英文文字框，在画布显示可勾选候选；用户点击“加入蒙版”后才绘制到蒙版。对置信度低的候选默认不选中。
2. 交互分割：优先选择可离线、许可可用且体积可控的 SAM 小型模型；若其运行环境或发行体积不满足约束，可使用本地 OpenCV GrabCut 作为交互框选分割实现。P4 的 GrabCut 实现支持框选、预览覆盖层、应用及清除；前景/背景点交互留给后续优化。仅在“应用到蒙版”后合并。若模型缺失，禁用功能并给出本地模型目录说明。
3. 所有候选必须可以单独删除、批量选择、反选，且合并为一个可撤销的历史步骤。
4. 对 OCR/交互分割结果做坐标变换测试；CPU 可运行；对于耗时模型应移入工作线程，P4 的小图同步框选仅用于候选预览。
5. 更新第三方清单、许可证文件、体积审计和用户文档。

验收：断网条件下，在包含中文文字的自有图片上显示候选、用户确认后生成正确蒙版并调用 LaMa；确保发行目录仍低于 9GB。若模型许可或实际体积不满足，停止并报告，不用替代模型擅自扩大范围。
