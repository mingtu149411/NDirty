# Codex 提示词：P1 图像导入与预览画布

在既有 NDirty P0 工程上工作。请只完成 P1：本地单图导入与预览工作台，不实现蒙版绘制或模型推理。

效果优先约束：任何显示缩放只可影响预览，原始像素尺寸、比例和坐标必须完整保留，供后续蒙版与补全引擎使用。

要求：
1. 支持 PNG、JPG/JPEG、WEBP、BMP 文件选择与拖放；对损坏或不支持格式显示中文错误，不崩溃。
2. 建立 `ImageDocument`，保存原始绝对路径、Pillow 原图、原始尺寸、缩放、平移和未保存状态。绝不改写输入文件。
3. 使用 QGraphicsView 或等效画布实现适配窗口、滚轮缩放、按住空格/中键平移、100% 和适配按钮。
4. 显示文件名、像素尺寸、缩放比例；状态栏显示“仅本地处理，未上传图像”。
5. 处理 Windows 中文与空格路径；必要时采用 `pathlib.Path`。
6. 对超大图实施明确的像素上限和友好提示，阈值集中配置并测试；不要静默降采样原图。
7. 写入可自动化的单元测试：格式筛选、文档元数据、屏幕坐标到原图坐标转换。若 GUI 难测，分离纯函数以便测试。
8. 更新 `项目状态.md` 和用户说明草稿。

验收：实际打开一个自有样例图，验证缩放和平移；运行测试；报告改动和未完成功能。不能下载模型或引入网络功能。
