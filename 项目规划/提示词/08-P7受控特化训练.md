# Codex 提示词：P7 受控特化训练（可选）

在开始前，检查 `04-训练与特化策略.md` 中四个启动门槛。若任一条件不满足，停止训练并只输出缺少条件与下一步；不要下载无授权数据、不要调用云端训练、不要把训练产物塞进发行目录。

效果优先约束：新权重必须对同一固定样例集做盲评和非蒙版像素校验；只有整体效果不低于默认 LaMa 的保比例 ROI 管线时才可替换默认模型。

如果门槛都满足，请在 `D:\xuexishiyong\水印项目\NDirty` 内完成一个可重复的本地特化实验，遵守以下流程：

1. 检查训练数据清单与授权字段；只使用明确标为可训练的数据。按原图划分 train/validation/test，并输出哈希去重报告。
2. 编写合成遮挡生成器，覆盖文字、半透明文字、污渍、黑块、马赛克；保存随机种子、遮挡形状和位置，确保同一配置可复现。
3. 先运行未修改 LaMa 的基线评测，记录指标、耗时、显存/内存、模型大小及失败样例。
4. 按低风险优先顺序实验：蒙版膨胀/羽化与预后处理 → 轻量模型或量化 → 许可证允许时的小型微调。一次只改一个变量，禁止直接训练基础大模型。
5. 所有代码、配置、日志和报告写入 `training/`；大型数据、检查点和缓存进入 `.gitignore`。每项实验可通过固定命令重跑。
6. 用固定测试集做定量和人工盲评；列出相对基线的提升与退化。不得只展示成功案例。
7. 仅当满足质量不低于基线、许可证合规、离线可推理、CPU/目标硬件可用、最终发行包 <10GB 时，才把最终权重复制到 `models/` 并接入应用；否则不替换默认模型。
8. 更新 `第三方清单.md`、模型 SHA-256、许可证、体积脚本和用户指南，然后执行离线回归测试。

最终报告必须包含：是否达到启动门槛、数据授权统计、可复现实验命令、基线/候选对比表、最大失败案例、是否纳入发布包、最终包精确大小。不得宣称恢复了被遮挡区域的真实原始内容。
