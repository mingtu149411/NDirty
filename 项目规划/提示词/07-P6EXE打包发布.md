# Codex 提示词：P6 Windows EXE 打包与发布

在 NDirty P5 全部验收通过后，制作离线 EXE 发行包。不得改变业务功能；若发现功能缺陷，请先报告并修复后再打包。

效果优先约束：打包不能替换、量化或遗漏已验收权重/图像处理依赖；必须在干净环境重复固定质量样例与非蒙版像素校验，而不只验证程序能启动。

要求：
1. 使用固定版本 Python 环境和 PyInstaller（或给出选择理由）创建可重复构建脚本。脚本要收集 Qt 插件、ONNX Runtime DLL、模型、许可证、文档与默认配置。
2. 输出 `dist/NDirty/` 便携版及可选安装器；不得依赖用户已有 Python、pip、网络、模型下载或环境变量。
3. 使用资源路径工具兼容 PyInstaller 的 `_MEIPASS` 与开发环境；禁止硬编码开发机绝对路径。
4. 生成 `版本信息.txt`、`THIRD_PARTY_NOTICES.md`、`SHA256SUMS.txt` 和中文 `用户指南.md`。用户指南包含离线使用、模型位置、原图保护、已知限制和授权提醒。
5. 在未安装 Python 的干净 Windows 环境完成：启动、导入、蒙版编辑、LaMa 推理、项目保存、导出、退出重启的烟雾测试。
6. 执行 `check_size.ps1`，发布包总量必须 <10GB，目标 <9GB；明确列出最大文件。如超过上限，移除非必要构建残留，绝不删除用户数据。
7. 不要把 `.venv`、pip 缓存、开发测试资产、源码映射、大型可选模型一并加入发行目录。

最终报告：精确发行路径、版本、SHA-256、清洁环境测试结果、最终体积、已知限制和回滚方式。
