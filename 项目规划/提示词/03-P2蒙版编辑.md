# Codex 提示词：P2 蒙版编辑

在 NDirty P1 的基础上，只实现人工蒙版编辑。蒙版是原图同尺寸、单通道 uint8：黑色(0)表示保留，白色(255)表示需要补全。

效果优先约束：蒙版所有编辑必须精确对应原图坐标；不能在缩放预览分辨率上保存蒙版，也不能对蒙版作隐式缩放或模糊。

完成：
1. 将半透明红色蒙版叠加于原图，提供显示/隐藏、透明度和边缘预览。
2. 实现画笔、橡皮、矩形选区、套索选区；笔刷大小可调，所有交互精确映射至原图像素坐标。
3. 加入撤销/重做；大图历史记录应保存受影响矩形或压缩差异，避免每一步复制整图。
4. 支持清空蒙版，但必须有确认对话框；支持导入/导出单通道 PNG 蒙版。
5. 支持保存 `.ndirty` 项目：以 ZIP 保存 `project.json`、`mask.png` 和必要的显示参数，但不复制原图；重新打开时若原图缺失应提示重新定位。
6. 画布在缩放和平移后依然保证笔划落点正确；添加针对坐标映射、蒙版合并、撤销/重做和项目序列化的测试。

验收：在小图与大图上画出/擦除蒙版；导出再导入后像素一致；运行测试。不要实现模型推理或自动识别。
